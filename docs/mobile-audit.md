## 1. Маркет

**Главный вывод: самая серьёзная проблема — не визуал, а то, что экран фильтров по большей части не работает.** Он выглядит функциональным, но из ~15 параметров бэкенд реально читает только `q`, `type` и `sortBy`. Визуально эталонные экраны — Маркет (витрина) и Сервисы; остальные 6–7 экранов не проходили рестайлинг.

### 🔴 Критично — сломанная функциональность

1. **Фильтры маркета — пустышка** (`mobile/src/api/market.ts:199-212`). Клиент шлёт `priceMin/priceMax/region/brand/model/yearFrom/…` в `/market/search|filter`, но эти эндпоинты читают только `minPrice/maxPrice/location`, а brand/model/год/пробег/топливо/КПП/кузов/привод не парсят вообще (их понимают только пер-категорийные `/market/cars`, `/market/parts`). Чинить либо на бэке (научить search/filter этим параметрам + редеплой), либо на клиенте (звать пер-категорийные эндпоинты).
2. **Категория «Чистка» в поиске всегда пуста** — на бэке нет ветки `dry-cleaning` в search/filter.
3. **Поиск на витрине закрывает клавиатуру** (`MarketScreen.tsx:83`) — не-silent загрузка после debounce размонтирует список вместе с TextInput.
4. **Детали объявления из Избранного/Поиска — «пустые»** (`MarketListingDetailsScreen.tsx:52`) — экран не рефетчит по id, а поиск отдаёт усечённые объекты без описания/галереи/продавца; заодно не считаются просмотры.
5. **Невидимые кнопки в деталях** — иконки «сравнить/закладка» цвета `#111` на тёмном фоне.
6. **Сравнение «теряет» объявления** (`CompareScreen.tsx:100`) — клиент просит `limit: 200`, бэкенд молча режет до 120 → «Не найдено».
7. **Подбор авто**: зелёный текст успеха нечитаем; слово «Backend» в пользовательской копии; серверный баг — уведомление о заявке создаётся только по cookie-JWT, мобильные (Bearer) его не получают.

### 🟠 Заметные баги фронта

- **Отзывы**: черновик затирается при голосовании/refresh; нет KeyboardAvoidingView; полоска рейтинга рисует 8% при нуле.
- **Редактирование объявления**: фото с камеры затирает весь набор (мёртвый тернарник `isVehicle ? [uri] : [uri]`); нельзя удалить отдельное фото; правки теряются при свайпе назад (то же в Создании).
- **Гонки запросов** (витрина, поиск, избранное): нет отмены — быстрое переключение категорий может показать чужую выдачу.
- **Числовые поля** Create/Edit принимают любой текст.
- **Не-silent `load()` при каждом фокусе** (Избранное, Мои объявления, Сравнение, Аналитика) — спиннер при каждом возврате на вкладку.
- Deprecated `MediaTypeOptions.Images` в пикере.

### 🟡 Визуальный долг (легаси-экраны)

Не прошли рестайлинг: Детали объявления, Поиск/фильтры, Избранное, Сравнение, Аналитика, Подбор авто, Редактирование, Отзывы. Паттерны:
- толстые рамки `borderWidth: 1` вместо hairline;
- сырые hex (`#fff`, `#111`, `#f5a400`, tailwind `#b91c1c`/`#15803d`/`#14843b`) вместо токенов — в Аналитике график красный;
- hero-заголовки, дублирующие нативный хедер (Сравнение, Аналитика, Подбор, Edit, Избранное);
- плоские чипы вместо анимированного сегмента с бегунком;
- легаси-«primary» (`surfaceHi` + `#fff`) вместо белого акцента;
- пустые состояния в карточках вместо центра экрана.

### 🟢 Полировка

Склонение числительных («1 отзывов», «2 лет»); `RefreshControl` без tintColor; тач-таргеты 24–38px; цены без разделителей тысяч; «Сбросить» не сбрасывает категорию; нет пагинации витрины (limit 40 при поддержке `page`).
